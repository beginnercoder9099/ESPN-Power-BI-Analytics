# ESPN Cricket Performance Analysis | Power BI

## Project Overview

An interactive Power BI dashboard designed to explore cricket player statistics across three performance areas: batting, bowling, and fielding. The report organizes player-level metrics into dedicated pages, allowing users to select players and review their performance statistics.

## Project Objectives

- Organize cricket performance statistics into clear analytical categories.
- Explore player-level batting, bowling, and fielding metrics.
- Provide an interactive way to review individual player statistics.
- Support performance comparisons and exploratory analysis.

## Tools & Technologies

- Microsoft Power BI
- Power BI slicers and KPI cards
- Data modeling and aggregation
- Data visualization

## Dashboard Modules

### 1. Batting Analysis

Examines batting statistics, including runs, matches, innings, balls faced, batting average, strike rate, highest score, boundaries, half-centuries, centuries, and career span.

### 2. Bowling Analysis

Organizes bowling statistics, including wickets, overs, runs conceded, bowling average, strike rate, economy, maiden overs, best bowling figures, and four- and five-wicket hauls.

### 3. Fielding Analysis

Presents fielding statistics, including catches, dismissals, stumpings, matches, innings, and dismissals per innings.

## Interactive Features

- Player selection through slicers.
- Separate report pages for batting, bowling, and fielding.
- KPI cards for reviewing selected statistical measures.

## Analytical Applications

- Explore differences in player performance.
- Review batting, bowling, and fielding records.
- Identify players and performance metrics for further investigation.
- Support cricket statistics reporting and exploratory analysis.

## How to Use

1. Download the Power BI file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Follow any data-source or refresh prompts if required.
4. Navigate between Batting, Bowling, and Fielding.
5. Use the player slicer to explore the available statistics.

## Data & Calculation Notes

The report contains player-level batting, bowling, and fielding fields. Aggregation settings should be validated before interpreting rate-based measures, including batting average, strike rate, bowling average, and economy.
